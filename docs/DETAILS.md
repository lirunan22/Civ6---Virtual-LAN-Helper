# 文明 VI · Mac 联机发现助手

一个独立运行的小插件，帮助已通过 WireGuard、ZeroTier、蒲公英等虚拟网络互通的玩家发现文明 VI 局域网房间。无需安装 Python 或修改游戏文件。支持 **macOS 12 及以上、Apple Silicon（含 M4）和 Intel**，同一个通用安装包。

## 下载与使用

从本仓库 [v0.1.1 Release](https://github.com/lirunan22/Civ6---Virtual-LAN-Helper/releases/tag/v0.1.1) 下载 `Civ6-Discovery-Helper-0.1.1-mac-universal.zip`，解压后打开 `Civ6 Discovery Helper.app`。这是 Mac 的原生可执行应用，不是 Windows `.exe`。下载无需仓库权限；插件不上传 IP、日志或游戏信息。

1. 玩家先连接同一个虚拟网络，确认客户端与房主的虚拟网 IP 可以互通。
2. 房主在文明 VI 创建「多人游戏 → 局域网」房间。通常只需要搜索房间的客户端运行插件。
3. 在插件填入**房主的虚拟网 IPv4**，点「按房主地址自动选择」，检查本机 IP 确实来自 VPN。也可以通过网卡列表选择或手动填写。
4. 先不勾选兼容模式，点击「开始监听」。检测到游戏进程并记录基线后，回游戏进入或刷新局域网列表。
5. 插件捕捉游戏新建的临时端口，从本机虚拟网 IP 和游戏同一个源端口，向房主 UDP 62900 补发一次 `8d e8 fc 70`。房主按游戏协议回复给原游戏端口。
6. 出现「端口占用 / Address already in use」时，点停止，勾选「授权兼容模式」再开始。macOS 会弹出管理员授权；授权完成后再回游戏刷新列表。取消授权不会继续发包。
7. 联机后可以停止、关闭插件。停止或退出会断开临时发送助手；未安装守护进程、启动项、驱动或系统服务。兼容会话最长 30 分钟，超时后需重新开始。

如果 macOS 要求本地网络权限，请在「系统设置 → 隐私与安全性 → 本地网络」允许本工具与文明 VI。下载包使用临时签名，**未做 Developer ID 签名或 Apple 公证**；右键打开或按 macOS 来源确认提示处理。不要将权限提示当成已经联机成功。

## 普通模式与兼容模式

Mac 与 Windows 的 socket 复用语义不同；不能照搬原脚本的 `SO_REUSEADDR` 并假定游戏端口一定能共享。普通模式同时设置 `SO_REUSEADDR` 和 `SO_REUSEPORT`，只短暂绑定选定 IP/端口，发包后立即关闭。

若游戏没有允许共享，该绑定仍会失败。兼容模式经系统授权临时使用原始 UDP socket：由内核构建 IPv4 头，工具只补齐原游戏源端口的 UDP 头和固定 4 字节请求，不与游戏争抢端口。只向本次填写的一个房主地址/62900 发包，不抓包、不注入、不转发后续游戏会话；用户密码由 macOS 处理，插件不会读取或保存。

授权助手只接受此插件的本机连接，重新核验请求端口属于同一用户的文明 VI 进程和当前 socket 身份；不能接受任意数据或任意目标。关闭连接立即结束，单会话最多 30 分钟、每秒最多 10 次。

## 日志与排错

| 现象 | 操作 |
| --- | --- |
| 未检测到游戏 | 打开原生 Mac 文明 VI 并进入游戏；Steam/Aspyr 启动器本身不算游戏。支持 Civ6、Civ6_Exe、Civ6_Exe_Child、Civilization VI 等原生进程名，不承诺 Wine/CrossOver/Windows 版。 |
| 没有新端口 | 开始监听后再刷新游戏局域网列表。已有端口只记录基线；本版按 macOS 动态端口起点识别候选，不保证所有游戏版本的协议一致。 |
| 本机地址无效/离线 | 重连 VPN，刷新网卡并重新选择这台 Mac 的虚拟网 IP，不能把房主 IP 填到本机。 |
| 无法读取游戏 UDP 端口 | 游戏可能正在退出，或 macOS 拒绝读取。重开游戏/工具后重试；该版本不会绕过系统保护。 |
| 端口占用 | 使用授权兼容模式，再刷新游戏列表。 |
| 已发送但看不到房间 | 仅表示系统接受发包；检查房主已建 LAN 房间、VPN 路由、防火墙、双方 UDP 62900 及返回路径。 |
| 看见房间却无法加入 | 已进入后续会话；检查游戏/DLC/模组版本一致，双方通常使用 UDP 62056 的会话流量可达。插件不会代理此流量。 |
| 使用 Tailscale 默认地址 | 允许填写 100.64.0.0/10，但上游报告文明 VI 的后续会话可能不正常；本插件不能保证该地址段联机。 |

只接受 RFC1918 或 VPN 的 CGNAT 私网 IPv4，不提供公网穿透或 IPv6 支持。工具不会配置 VPN、路由、防火墙或网卡优先级。IP 和屏幕日志仅本次运行，停止不是“房间已找到”的确认。

## 构建与验证

在安装 Xcode Command Line Tools 的 Mac 上运行：

```bash
python3 build.py
```

输出位于 `artifacts/`。开发构建没有自动发包。`--test` 用于一次性 CI Mac，运行进程/socket 读取、UDP 回环与临时 root 回环测试、原生 UI 冒烟；不会运行实际文明 VI 或外部 VPN。源码包可在目录内运行 `python3 build.py`，保留随包 LICENSE 即可。

验证边界见仓库 [VALIDATION.md](../VALIDATION.md)：CI 可验证原生启动、通用架构、签名归档、协议和回环回复；**真实游戏房间发现、VPN 跨机联机、用户 Mac 的管理员授权和防火墙许可仍需要两台游戏机器实测**。
